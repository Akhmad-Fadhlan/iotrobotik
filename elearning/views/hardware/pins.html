Edge Connector & Pin GPIO

Konektor tepi (Edge Connector) di bagian bawah papan micro:bit menyediakan akses ke berbagai pin ekspansi.

  • Pin Besar (0, 1, 2): Merupakan pin General Purpose Input Output (GPIO) utama. Pin ini dapat digunakan untuk membaca sensor analog/digital atau mengirim sinyal output (seperti menyalakan LED eksternal atau mengontrol servo). Sangat mudah dihubungkan menggunakan kabel jepit buaya (crocodile clips).
  • Pin Daya (3V & GND): Pin 3V menyediakan catu daya 3.3 Volt untuk menyalakan perangkat elektronik eksternal berdaya rendah, sedangkan GND (Ground) berfungsi sebagai referensi negatif bersama.
  • Pin Kecil (3 s/d 20): Menyediakan jalur ekspansi untuk komunikasi serial berkecepatan tinggi seperti protokol I2C (Inter-Integrated Circuit) untuk sensor eksternal, SPI (Serial Peripheral Interface), dan UART.
