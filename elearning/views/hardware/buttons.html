Tombol Fisik A & B

Terdapat dua tombol input taktil fisik berlabel A dan B di bagian depan micro:bit.

  • Tombol A (Kiri): Terhubung secara elektronik ke GPIO Pin 5.
  • Tombol B (Kanan): Terhubung secara elektronik ke GPIO Pin 11.
  • Pemicu Event (Interrupts): Tombol-tombol ini berfungsi untuk mendeteksi interaksi langsung dari pengguna. Kita dapat mendeteksi penekanan tombol A, tombol B, atau penekanan keduanya secara bersamaan (A+B).
  • Pemrograman: Dalam Blockly menggunakan blok event ketika tombol ditekan, dan dalam Python menggunakan button_a.is_pressed() atau event listener nirkabel.
